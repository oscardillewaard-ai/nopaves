# Licentie voor de code: de keuze

Er is nog geen licentie gekozen. Zonder licentie geldt standaard: alle rechten voorbehouden. Anderen
mogen de code dan bekijken (de repository is openbaar), maar niet hergebruiken of verspreiden.

Dit gaat alleen over de code. De data (OpenStreetMap, PDOK) en de graafblokken houden hun eigen
licentie (zie de README). De graafblokken vallen sowieso onder de ODbL.

| Optie | Wat het betekent | Past bij |
|---|---|---|
| **MIT** | Iedereen mag alles, ook in gesloten software, als de naamsvermelding blijft. | Zo veel mogelijk gebruik, weinig gedoe. |
| **Apache 2.0** | Als MIT, plus een expliciete octrooiclausule en een plicht om wijzigingen te melden. | Als octrooien een zorg zijn. |
| **GPL 3.0** | Hergebruik mag, maar wie een aangepaste versie verspreidt, moet die ook onder GPL delen. | Verbeteringen moeten open blijven. |
| **AGPL 3.0** | Als GPL, en geldt ook als iemand de app als website aanbiedt. | Voorkomen dat iemand er een gesloten dienst van maakt. |
| **Alle rechten voorbehouden** | Niemand mag de code hergebruiken zonder toestemming. | Eerst rustig nadenken, of commercieel houden. |

Kiezen is snel gedaan: voeg in de root een `LICENSE`-bestand toe met de tekst (GitHub: Add file →
Create new file → naam `LICENSE` → "Choose a license template") en pas de regel "Licentie" in de
README aan.
